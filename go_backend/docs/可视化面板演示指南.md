# 可视化面板演示指南（录视频优先，无需 Docker）

更新时间：2026-04-09
适用场景：本地录视频演示 SpotTruth 网关可观测性

## 一、结论先说

1. 当前网关已支持 Prometheus 标准指标接口：`GET /metrics`。
2. 录视频场景下，不强制 Docker。
3. 推荐本地直接启动 Prometheus + Grafana，步骤更快、故障点更少。

## 二、准备条件

1. Go 网关已启动（默认 `http://127.0.0.1:8080`）。
2. 指标可访问：

```bash
curl -sS http://127.0.0.1:8080/metrics | head -n 30
```

3. 可选：如需 JSON 快照排障，使用：

```bash
curl -sS http://127.0.0.1:8080/metrics/json
```

## 三、安装与启动（macOS，无 Docker）

### 3.1 安装

```bash
brew install prometheus grafana
```

### 3.2 启动 Prometheus

```bash
cd /Users/yllmis/go_projects/SpotTruth/go_backend
prometheus --config.file=observability/prometheus.yml
```

默认地址：`http://127.0.0.1:9090`

### 3.3 启动 Grafana

```bash
grafana server --homepath /opt/homebrew/opt/grafana/share/grafana
```

默认地址：`http://127.0.0.1:3000`
默认账号密码：`admin / admin`

## 四、Grafana 配置步骤

1. 进入 `http://127.0.0.1:3000`。
2. 添加数据源：Prometheus。
3. URL 填写：`http://127.0.0.1:9090`。
4. 点击 Save & test。

## 五、面板查询（建议至少 6 张）

1. 总请求量（Counter）

```promql
spottruth_requests_total
```

2. 在途请求（Gauge）

```promql
spottruth_in_flight_requests
```

3. 状态码分布（按 code_class）

```promql
spottruth_http_status_total
```

4. 限流命中

```promql
spottruth_limiter_rejected_total
```

5. 熔断降级命中

```promql
spottruth_circuit_degraded_total
```

6. 熔断状态值（0=closed, 1=half-open, 2=open）

```promql
spottruth_circuit_state_value
```

## 六、录视频建议流程（3-5 分钟）

1. 展示网关基础状态
   - `healthz`、`readyz`、`metrics`。
2. 在 Grafana 空面板展示实时指标。
3. 运行压测或故障注入脚本制造变化。
4. 展示图表变化（请求上涨、限流命中、熔断降级）。
5. 总结“网关具备稳定性保护与可观测能力”。

## 七、流量与故障注入命令

### 7.1 生成请求流量（可循环执行）

```bash
for i in $(seq 1 200); do
  curl -sS http://127.0.0.1:8080/healthz > /dev/null
  curl -sS http://127.0.0.1:8080/api/v1/search > /dev/null || true
done
```

### 7.2 熔断故障注入

```bash
cd /Users/yllmis/go_projects/SpotTruth/go_backend
bash scripts/fault_injection_circuit_breaker.sh http://127.0.0.1:8080 /api/v1/search 8
```

## 八、可选 Docker 方案（不是必须）

如果后续需要一键复现给他人，再补 Docker Compose。当前录视频阶段，不建议优先做 Docker 化，以免增加环境变量与网络排障成本。
