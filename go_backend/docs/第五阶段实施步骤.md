## 二、已落地能力

1. 分桶限流
   - 新增中间件：`internal/middleware/bucket_limiter.go`。
   - 维度：优先 API Key，无 API Key 时回退到客户端 IP。
   - 响应：`429` + `GATEWAY_RATE_LIMITED` + `request_id` + `retry_after`。

2. 请求追踪标准化
   - 新增中间件：`internal/middleware/request_id.go`。
   - 统一注入/透传 `X-Request-ID`。
   - 日志输出中新增 `request_id` 字段。

3. Prometheus 指标
   - `/metrics` 输出 Prometheus exposition 文本（可被 Prometheus 直接抓取）。
   - `/metrics/json` 保留原快照格式，方便临时脚本与人工排查。

## 三、新增配置项

1. `BUCKET_LIMIT_ENABLED`
2. `BUCKET_LIMIT_REQUESTS`
3. `BUCKET_LIMIT_WINDOW`
4. `BUCKET_LIMIT_RETRY_AFTER_SECONDS`
5. `BUCKET_LIMIT_PREFER_API_KEY`

## 四、可视化看板评估（你当前场景：录视频）

1. 能否实现：可以实现。
2. 最低成本方案：
   - 保持当前 `/metrics`。
   - 本地直接启动 Prometheus + Grafana（可不使用 Docker）。
3. 是否必须 Docker：不是必须。
   - 录视频场景下，不强制要求 Docker。
   - 如果你追求一键复现，再补 Docker Compose 更合适。

## 五、建议演示路径（无 Docker）

1. 启动 Go 网关。
2. 用压测或故障注入触发限流/熔断。

4. Grafana 新建 4 个核心面板：
   - `spottruth_requests_total`
   - `spottruth_http_status_total`
   - `spottruth_limiter_rejected_total`
   - `spottruth_circuit_degraded_total`
