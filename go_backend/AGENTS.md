# AGENTS 协作约定（SpotTruth）

本文件仅适用于当前/go_backend及其子目录。

## 目标
- 以“增量修改、可验证、可追踪”为原则推进开发。
- 保持 Go 网关、Python 算法与 Web 联调链路的一致性。

## 通用规则
- 代码、注释、文档、提交信息统一使用中文。
- 默认优先小步修改，不做无关重构。
- 除非需求明确，不新增大规模自动生成代码。
- 修改涉及接口行为时，需同步更新对应文档。

## Go 网关规则
- 配置项必须支持环境变量覆盖，并提供默认值。
- 生产相关改动优先保证超时、限流、鉴权与可观测性。
- 网关能力变更需同步更新 go_backend/docs/设计与可扩展性说明.md。

## Python/Agent 规则
- Agent 与工具链优先复用现有模块（new_idea/step6_mcp_tools.py）。
- 涉及多源爬取逻辑时，需明确区分“已落地能力”与“占位/TODO”。

## 验证要求
- 完整模块改动需补充并通过对应单测。
- 非完整模块改动按最小验证原则执行（至少保证可运行/可编译）。

## 提交说明
- 提交信息建议格式：feat/fix/docs/refactor/chore。
- 重要改动需在说明中写清“修改了什么、为什么这样改、影响范围”。
