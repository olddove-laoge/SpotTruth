# SpotTruth 社区版 - 商品评价平台

## 产品定位
类似"单机小红书/虎扑"的商品评价社区，用户可以查看商品避雷分析、分享购物体验、对比商品。

## 核心功能

### 1. 首页推荐
- **个性化推荐**：基于用户浏览历史、搜索记录推荐商品
- **热门商品**：按分析热度、评论数量排序
- **最新上架**：新收录的商品分析
- **品类分区**：手机、数码、家电、美妆等

### 2. 搜索功能
- **链接搜索**：直接粘贴淘宝/京东商品链接
- **文字搜索**：品牌名+商品名（复用搜索模块）
- **历史搜索**：记录用户搜索历史

### 3. 商品详情页
- **基础信息**：价格、店铺、销量
- **评价分析**：
  - 整体情感分布（正面/中性/负面）
  - 关键词词云
  - 典型差评/好评展示
- **平台数据**：
  - 淘宝评价分析
  - 小红书避雷笔记
  - 黑猫投诉数据
- **历史走势**：价格走势、评价趋势

### 4. 商品对比
- **选择商品**：最多支持4个商品对比
- **对比维度**：
  - 价格对比
  - 情感分析对比（好评率）
  - 关键词对比（差评点）
  - 投诉数量对比
- **生成报告**：一键生成对比报告

### 5. 用户系统（后期扩展）
- **登录/注册**：微信登录、验证码登录
- **Token会话**：Access Token + Refresh Token（后端统一鉴权）
- **收藏功能**：收藏商品分析
- **浏览历史**：记录查看过的商品
- **我的评价**：用户可发表自己观点

#### 5.1 权限分层（补充）
- **普通用户**：可查询商品分析、查看任务进度、管理个人数据
- **管理员**：可强制刷新分析任务、重跑失败任务、执行运维操作
- **系统任务**：异步执行抓取与分析工具，不直接暴露给前端

### 6. 社区功能（后期扩展）
- **商品话题**：#双11避雷 #新品测评
- **用户笔记**：分享购物体验
- **问答**：提问关于商品的问题

## 技术架构

### 前端
- Web: React/Vue + Vant UI（移动端）
- 图表: ECharts

### 后端
- API: FastAPI/Flask
- 网关: Go API Gateway（Token鉴权、权限控制、限流）
- 数据库: MySQL + Redis
- 搜索引擎: Elasticsearch（商品搜索）

### 数据处理
- 爬虫: 定时任务抓取商品数据
- 分析: 复用现有分析模块
- 推荐: 基于用户行为的协同过滤
